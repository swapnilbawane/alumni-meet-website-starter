# Customization checklist

- Add your organisation name and an appropriately licensed logo.
- Update event title, date, time, venue, city, event description and RSVP destination in `website/index.html`.
- Replace placeholder contact addresses and links. Search for `YOUR-`.
- Update the API URL after deploying your own Apps Script.
- Update the cache key if maintaining multiple event sites from the same browser origin.
- Review the public-field allowlist and Sheet headers.
- Ask permission before publishing alumni names, photos, roles or social links.
